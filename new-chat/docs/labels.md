# Label Guide

팀에서 자주 사용할 라벨 기준입니다.

## 이슈 타입

- `feature`: 신규 기능 또는 기능 개선
- `refactor`: 구조 개선, 책임 분리, 기술 부채 정리
- `daily`: 데일리 작업 공유
- `bug`: 버그 수정

## 우선순위

- `priority:high`
- `priority:medium`
- `priority:low`

## 영역

- `backend`
- `api`
- `auth`
- `database`
- `deployment`
- `docs`

## 상태

- `blocked`
- `in-review`
- `ready`

## 사용 예시

- 로그인 기능 개발: `feature`, `backend`, `auth`, `priority:high`
- 회원 서비스 분리 작업: `refactor`, `backend`, `priority:medium`
- 2026-05-03 데일리 공유: `daily`, `backend`

## GitHub에서 라벨 만드는 방법

1. 레포로 이동합니다.
2. `Issues` 탭을 엽니다.
3. `Labels`를 클릭합니다.
4. 위 목록대로 라벨을 생성합니다.
