# Architecture Overview

## 목적

이 문서는 서비스의 전체 구조와 주요 책임을 빠르게 이해하기 위한 개요 문서입니다.

## 예시 구성

- `api`: 외부 요청을 받는 계층
- `application`: 유스케이스와 서비스 로직
- `domain`: 핵심 도메인 모델과 규칙
- `infrastructure`: DB, 메시지 큐, 외부 API 연동
